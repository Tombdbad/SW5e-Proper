# AUDIT 03b: Feature trace, AREA B (Items & gear), 2026-11-07, branch `audit`, read-only

## Plain-English summary
- 24 features traced. **WIRED 19, PARTIAL 4, MISSING 1, DEAD 0, UNKNOWN 0.** (PARTIAL: B-02, 04, 16, 20; MISSING: B-24.) Rule used: a browser step that checks the result counts as a test, so B-19 and B-21 are WIRED even without a unit test.
- Items are the best-covered part of the game: 20 unit-test files in `tests/items/` (about 135 tests by my count of `test(` lines), plus three browser scripts (`e2e/items.mjs`, `e2e/play.mjs`, `e2e/works.mjs`) that buy, sell, wield, attune, fit mods, mine and craft through the real UI.
- **Five most important problems in this area:**
  1. **Two docs are out of date about weapon properties.** `ITEM_TODO.md` and the guide (section 10.9) say auto, penetrating, dire, piercing and two-hand thrown/versatile damage are not read in a fight. The code reads penetrating, dire, piercing and versatile (`useCombat.ts:862-863, 1568-1569`) and tests exist (`fightrules.test.ts`, `weaponprops.test.ts`). What is genuinely still unread was not re-counted (B-02, B-24).
  2. **Downtime, crafting, gambling, gathering, color crystals and loot have no unit test.** Their logic functions are called only from the 11,000-line `GameBoard.tsx` and nowhere in `tests/`. Only the browser script exercises them (B-16, B-19, B-20, B-21).
  3. **The "Downtime" tab only exists in a test build** (`GameBoard.tsx:3835` sends you back to "Here" unless `VITE_TEST_MENU=1`). In the normal build, the activities are reached through people (the jobs panel, `GameBoard.tsx:3875`). The e2e (`play.mjs:1380`) clicks the Downtime tab, so it can only pass on a test build. Which build the e2e runs against was not determined (B-20).
  4. **Weight, containers, survival and rarity have unit tests but no browser test** (the e2e has no step for encumbrance, containers or hazards) (B-05, B-08, B-09, B-11).
  5. **Enhanced items (1,918 rows):** the item model coverage tool covers only the 507 base items (all 507 have a model: 286 own, 221 shared by kind, 0 with none; I ran it). Enhanced rows' models were not measured (B-04, B-23).
- Guide check: "every one of 507 items has a model" is confirmed by `tools/model-coverage.ts` output. "1,918 enhanced rows have a model" is UNVERIFIED.

How "Browser-verified" was judged: YES only if a step in `e2e/*.mjs` does it. I did not run any test or e2e in this session.
